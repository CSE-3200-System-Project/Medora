# Claim--evidence map

This map is deliberately stricter than the prose plan. `Supported` means the
claim has a repository artifact or an authoritative external source. `Protocol`
means the method is specified but no result is claimed.

| Claim | Evidence | Status |
|---|---|---|
| Medora exposes 21 assistive-AI endpoints in nine groups | `docs/softwarex/medora_softwarex.tex`, Table `ai-surface` | Supported |
| The AI/ML surface contains 19 components, 13 deterministic | Row-level count in `docs/softwarex/medora_softwarex.tex`, Table `components` | Supported inventory fact, but deliberately not used as a proxy for AI depth; the paper instead separates learned tasks from deterministic authority |
| The deployed text-provider default is Groq `openai/gpt-oss-120b`, with Gemini, Cerebras, and deterministic mock alternatives | `backend/app/core/config.py`; provider adapter and environment examples | Supported as current configuration; provider availability and prices remain time-sensitive |
| Chorui uses 24 registry entries over 23 intents | `backend/app/services/chorui_navigation_registry.py`; SoftwareX manuscript | Supported |
| Chorui's registry contains 11 patient entries, 11 clinician entries, and two shared entries, with no administrative route | registry source and SoftwareX manuscript | Supported; fixed build-time reachability, not model-selected tools |
| The medicine layer contains 7,389 canonical drugs and 67,001 brands | `data/medicine_reference/Final_Medicine_Dataset.csv`, build script, SoftwareX corpus table | Supported |
| Privacy baseline is 94.7% precision, 75.5% recall, and 3.2% false redaction | `docs/softwarex/generated/safety_results.json` | Supported on 134 synthetic production-path cases (original rule layer, before the extension below) |
| Extended rules cover the previously-leaking classes (names, obfuscated emails, textual dates, bare IDs, addresses) | `backend/app/core/ai_privacy.py`; `tests/benchmarks/reports/safety_results.json` | On the 134-case set: recall 1.0, precision 0.969, over-redaction 2.4%. This is a DEVELOPMENT figure only — the rules were tuned against that set, so 1.0 is NOT a generalization/recall claim and is deliberately not headlined as one in the paper. |
