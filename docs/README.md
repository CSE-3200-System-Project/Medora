# Medora documentation map

Current normative documents are:

- `DATA_GOVERNANCE.md`
- `ROLE_PERMISSION_MATRIX.md`
- `REPRODUCING.md`
- `softwarex/medora_softwarex.tex`
- `softwarex/response_to_revision.md`
- the code and tests at the fixed release commit

Files such as `FINAL_REPORT.md`, `TESTING_REPORT.md`, `PROJECT_OVERVIEW.md`, and
`defense/` describe an earlier academic demonstration. They are retained for project
history, not as evidence for SoftwareX. Their approximate performance figures,
production-readiness language, offline health-write design, and anonymity wording
are superseded and must not be quoted in the paper or release metadata. Measured
claims for `v1.0.0` come only from versioned generated benchmark artifacts.
