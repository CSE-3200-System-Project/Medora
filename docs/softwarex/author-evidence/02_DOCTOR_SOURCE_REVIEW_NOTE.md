# Qualified doctor's actual source-review note

Give this short form to the doctor who already reviewed the sources. Ask them to describe
what they actually checked, not to certify 46,614 rows. Record an earlier review honestly;
if its date is unknown, say so and date this note when completed. Do not backdate it.
Keep the signed/email original privately; publish the agreed scope/result summary only.

1. **Reviewer:** [name; medical qualification; role; registration/professional affiliation
   if applicable]. Permission to identify the reviewer publicly: [yes/no].
2. **Date of review:** [actual date/range, or not recorded]. **Date of this note:** [date].
3. **Sources actually examined:** [select and describe S1 MedEx-described Kaggle,
   S2 MedEasy-described Kaggle, S4 DGDA-described Kaggle, S5 Mendeley V1;
   links/file identities are in generated/medicine_v2_full_build_manifest.json].
   [Do not tick sources not examined; identify versions or say version unknown.]
4. **What I did:** [e.g. examined the source websites/dataset descriptions; assessed their
   suitability for a Bangladesh medicine-identity lookup; checked selected generic-brand,
   strength/form or manufacturer records; number and selection of records if actually checked].
5. **Findings:** [what was found; examples/corrections if any; or no concerns observed in the
   limited checks performed]. Do not write "all correct" unless all relevant entries were checked.
6. **Concerns or unresolved matters:** [missing fields; ambiguous mappings; out-of-date
   registration; unknown completeness; other concerns; distinguish not assessed from none found].
7. **Scope of conclusion:** [own words]. If appropriate: "This review concerns the sources
   and the checks listed above. It does not validate every medicine row, establish national
   completeness/current registration, approve redistribution rights or establish prescribing safety."
8. **Confirmation:** [signature or affirmative reply from the reviewer; date].

Send-back request:

> Please fill these eight short fields to document the source review you already performed.
> We are not asking for a row-by-row audit or a clinical endorsement of the full corpus.
> Please state any corrections and anything you did not assess. If you did not review these
> specific sources, tell us; we will not describe that review as completed.

Recording an existing review may take roughly 10–15 minutes; that is an estimate, not a
deadline or guarantee. A new content audit takes longer and is not silently assumed here.
If the existing review cannot be confirmed, tell the authors so the paper's review assertion
can be removed or revised instead of inventing evidence. The optional 30-case content
spot-check remains separate, not mandatory whole-corpus validation.
