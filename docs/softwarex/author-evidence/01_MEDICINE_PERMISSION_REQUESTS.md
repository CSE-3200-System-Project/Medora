# Optional source-specific clarification requests

A valid applicable public licence already grants the uses it covers. These emails are
one way to resolve specific provenance/terms questions, not a requirement to collect three
new replies before submitting. See `../revisions/MEDICINE_LICENCE_DEADLINE_CHECK.md`:
S1 has a documented current MedEx terms conflict; S2's origin is uncertain; no contrary
DGDA redistribution restriction was established for S4. An applicable existing rights
basis or competent institutional assessment can answer the question without a new email.

These are unsent templates, not evidence of permission. Send from an author email account.
Keep replies and any private attachments outside the public repository. Return a redacted
reply or an approved summary so the source-permission record can be completed.

## Exactly what to return

For each of S1/S2/S4 return: source ID; who replied and their authority; reply date; the
identified input; allowed collection/use/redistribution scope; licence/conditions; and an
evidence copy or private evidence reference. An approved redacted summary can be public.
Silence, a generic acknowledgement or permission only to view the website does not answer
the requested public-distribution scope. A source owner's reply is evidence to assess,
not a guarantee concerning rights it does not control.

S5 Mendeley CC BY 4.0 attribution/change notice is already documented; no new email request
is prescribed for that documented basis. S3 is excluded from the new corpus. Until these
records are resolved, the selected multi-source public release remains gated. If permission
is declined or cannot be established, the affected contribution must be excluded or another
applicable basis documented; do not mark it cleared automatically.
